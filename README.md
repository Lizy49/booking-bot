# 🤖 Telegram-бот для онлайн-записи

Бот, через который клиенты записываются на приём (барбершоп, мастер, репетитор, студия): выбирают услугу, дату и время кнопками, а администратор сразу получает уведомление. Занятое время второй раз выбрать нельзя.

**Стек:** Python 3.8+, Telegram Bot API, SQLite. Внешние библиотеки не нужны.

## Возможности

**Для клиента**
- Запись в несколько нажатий: услуга → дата → время
- Показываются только свободные даты и время; выходные и прошедшие часы скрыты
- Раздел «Мои записи» с возможностью отменить запись
- Ограничение: не больше 3 активных записей на человека

**Для администратора**
- Мгновенное уведомление о новой записи и об отмене
- Команда `/admin`: список записей на сегодня и завтра

**Надёжность**
- Двойная запись на одно время невозможна: это гарантирует сама база данных (уникальный индекс), даже если два человека нажмут одновременно
- Данные из кнопок не считаются доверенными: время, дата и услуга проверяются заново на сервере
- Нельзя отменить чужую запись
- Имена пользователей экранируются, поэтому HTML-код в имени не сломает сообщения
- Ошибка в одном обновлении не останавливает бота

## Запуск

1. Создайте бота в Telegram: напишите **@BotFather**, команда `/newbot`, получите токен.
2. Узнайте свой ID у бота **@userinfobot**. Он нужен, чтобы получать уведомления.
3. Скопируйте `.env.example` в `.env` и заполните:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_id
   ```
4. Запустите:
   ```bash
   python bot.py
   ```
5. Откройте своего бота в Telegram и нажмите `/start`.

> ⚠ Файл `.env` содержит токен и не должен попадать на GitHub (он уже добавлен в `.gitignore`). Если токен случайно опубликован, отзовите его у @BotFather командой `/revoke`.

## Настройка под своего клиента

Откройте `config.py` и поменяйте:
- `SERVICES`: список услуг и цены
- `WORK_START`, `WORK_END`: часы работы
- `SLOT_MINUTES`: длительность одной записи
- `DAYS_OFF`: выходные дни
- `DAYS_AHEAD`: на сколько дней вперёд можно записаться

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Главное меню |
| `/book` | Начать запись |
| `/my` | Мои записи |
| `/admin` | Записи на сегодня и завтра (только для администратора) |

## Структура проекта

```
booking-bot/
├── bot.py            # запуск, получение обновлений от Telegram
├── handlers.py       # логика диалога: экраны, кнопки, проверки
├── scheduling.py     # расчёт дат и свободного времени
├── storage.py        # база данных SQLite
├── telegram_api.py   # обращения к Telegram Bot API
├── config.py         # настройки
└── test_bot.py       # автоматические тесты
```

Логика (`handlers.py`) не знает о сети: Telegram подменяется «заглушкой», поэтому весь диалог проверяется тестами без реального бота.

## Тесты

```bash
python -m unittest -v
```

Проверяются: расчёт расписания, полный сценарий записи, защита от двойной записи, подделанные данные кнопок, лимит записей, отмена, чужие записи, команда администратора, экранирование HTML.

## Что я реализовал и чему научился

- Работа с Telegram Bot API напрямую: long polling, inline-клавиатуры, редактирование сообщений
- Проектирование базы данных: частичный уникальный индекс SQLite для защиты от двойной записи
- Разделение кода на слои (интерфейс, логика, данные), благодаря которому бот можно тестировать
- Безопасная работа с секретами (`.env`) и недоверенными данными
